# Logistic Regression From Scratch

I implemented Logistic Regression from scratch using NumPy and pandas without using sklearn's LogisticRegression.

## Concepts

- Linear Function
- Sigmoid Function
- Log Loss
- Gradient
- Gradient Descent
- Weight Updates
- Probability Prediction
- Class Prediction
- Confusion Matrix
- Accuracy
- One-Hot Encoding

## Dataset

The dataset contains:

- Age
- Gender
- Device
- Hours Online
- Purchased

The goal is to predict whether a customer will purchase something.

## Workflow

Data
→ One-Hot Encoding
→ NumPy
→ Linear Function
→ Sigmoid
→ Loss
→ Gradient Descent
→ Prediction
→ Confusion Matrix
→ Accuracy

## Technologies

- Python
- NumPy
- pandas

## What I Learned

This project helped me understand how Logistic Regression works internally rather than simply using a machine-learning library.
